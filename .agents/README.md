# Agents

[Agent Skills](https://github.com/agentskills) layout: `.agents/skills/<name>/SKILL.md`. React Router’s official template uses the same path.

Root `AGENTS.md` is only an index so tools that look at the repo root know to load these files.

| Skill | When |
| --- | --- |
| [imports](skills/imports/SKILL.md) | Alias `@/` and module layers |
| [update-readme-todos](skills/update-readme-todos/SKILL.md) | After a change that finishes or reveals backlog |
| [no-unsolicited-changes](skills/no-unsolicited-changes/SKILL.md) | Always |
| [test-structure](skills/test-structure/SKILL.md) | `*.spec.ts` |

The web app also has the official React Router skill at `src/ui/web/.agents/skills/react-router`.
